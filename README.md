# THE ASCENT — V3.1 Summit & Story

Built on the complete V3.0.1 package.

## Changes
- Summit rocks use rounded, irregular subdivided 3D stone forms with smooth normals and snow caps; no more spiky cone outcrops around Liam.
- Five story captions enter alternately from left and right and drift vertically with scrolling. They fade and move out before the next chapter.
- Kept the original scroll-driven StairMaster steps, snowstorm transition, Liam, flag and separate GLB models.

## Files
- `index.html` — Three.js website and procedural Everest assets
- `assets/models/stairmaster-frame.glb`
- `assets/models/stairmaster-step.glb`
- `assets/textures/console-display.png`
